Areas of Expertise

Four high-impact security domains I actively research, learn, and build practical skills in.

01

Ethical Hacking

RED TEAM · PENTESTING · EXPLOITATION

Ethical hacking is the practice of using the same tools, techniques, and mindset as an attacker — but with permission, and with a report at the end. I approach every target systematically, from passive recon to privilege escalation.

I practice on platforms like Hack The Box and TryHackMe, working through real machines that simulate corporate environments, CTF-style challenges, and active directory attacks.

Reconnaissance Enumeration Exploitation Privilege Escalation Post-Exploitation Active Directory Pivoting Reporting
Recon & OSINTPassive and active information gathering — Nmap, Shodan, theHarvester.
ExploitationService and application-level exploitation using Metasploit and manual techniques.
Privilege EscalationLinux SUID/SUDO abuse, Windows token impersonation, kernel exploits.
Active DirectoryKerberoasting, AS-REP roasting, Pass-the-Hash, BloodHound mapping.

02

Web App Security

OWASP · API TESTING · BUG BOUNTY

Web application security is where I spend most of my time. I test both the frontend and backend attack surfaces — injection flaws, broken authentication, logic vulnerabilities, and API misconfigurations.

I follow the OWASP Testing Guide, use Burp Suite as my primary proxy, and build custom payloads for each target. I've explored bug bounty programs and PortSwigger's entire Web Academy curriculum.

SQLi XSS SSRF IDOR CSRF Auth Bypass XXE HTTP Smuggling API Security JWT Attacks
Injection AttacksSQL, NoSQL, LDAP, OS command, template injection — manual and automated discovery.
Authentication FlawsBroken auth, session fixation, JWT forgery, OAuth misconfigurations.
IDOR & Access ControlHorizontal and vertical privilege escalation via insecure object references.
API TestingREST and GraphQL API enumeration, mass assignment, over-fetching vulnerabilities.

03

AI / LLM Security

PROMPT INJECTION · RED TEAMING · ADVERSARIAL ML

As AI systems get deployed in critical products, they introduce entirely new attack surfaces. I research how language models can be manipulated — through inputs, tool calls, and agentic pipelines.

I study the OWASP LLM Top 10, MITRE ATLAS, and real-world AI incidents. I test prompt injection techniques, jailbreaks, and data exfiltration via multi-turn agent sessions.

Prompt Injection Jailbreaking Model Inversion Adversarial Inputs Data Poisoning Agent Hijacking Insecure Output Training Attacks
Prompt InjectionDirect and indirect prompt injection to override system instructions and exfiltrate data.
JailbreakingRole-play, context manipulation, and encoding techniques to bypass model safety filters.
Agent ExploitationMulti-turn attacks on autonomous agents with tool-use and memory capabilities.
MITRE ATLAS MappingClassifying AI threats using the adversarial ML threat landscape framework.
