Title "IDOR in /api/v1/orders/{id} Allows Horizontal Access to Any User's Order Data"

Severity High — CVSS 3.1: AV:N/AC:L/PR:L/UI:N/S:U/C:H/I:N/A:N (7.1)

OWASP A01:2021 Broken Access Control — CWE-284

Summary 2–3 sentence description of the vulnerability and root cause

Steps to Reproduce Numbered steps with exact HTTP requests / curl commands

PoC Burp request screenshot or video recording

Impact An attacker can enumerate all order IDs and read PII/payment method of any customer

Remediation Enforce server-side ownership check: verify requesting user owns the order_id before returning data
