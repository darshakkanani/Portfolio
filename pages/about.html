My Story

I started with CTF competitions — those puzzle-like hacking challenges — and quickly realized that real security requires going deeper. Understanding vulnerabilities at the code level, the protocol level, and the logic level.

Today I'm building a skill set across three high-impact security domains, actively participating in bug bounty programs, and sharing everything I learn through this site and blog.
